# Task 2B handover

The final allocation is `outputs/submission_task2b.csv`; submit it with
[TASK2B_POLICY.md](TASK2B_POLICY.md). This extends the existing Task 1/2A handover.
The Task 2B notebook is [TASK2B_NOTEBOOK.ipynb](TASK2B_NOTEBOOK.ipynb); copy its cells
into the team's shared final notebook. No existing final notebook was present here.

Run from `Datathon/` with the local datasets and checker copies described in
`data/README.md`:

```powershell
.venv/Scripts/python task2b/run_all.py
.venv/Scripts/python check_allocation.py outputs/submission_task2b.csv
.venv/Scripts/python task2b/integration_check.py
```

The Task 2B pipeline runs setup checks, capacity analysis, policy checks, greedy
baseline, independent exhaustive optimiser tests, exact search, independent
timeline tests, operational audit, repaired-reefer sensitivity, policy generation
and final submission validation. Sensitivity is the slowest step and may take a
few minutes. Task 2B requires pandas and the standard library; no solver install.
The independent MILP used for review is not a production dependency.

Three-task integration needs the local models and feature files generated by
`python task1/run_all.py` and `python task2a/run_all.py`. The combined final cell
in `inference_cell.py` loads models for Tasks 1/2A and displays/checks Task 2B.
`task2b/integration_check.py` checks its outputs against all three submission files.

The nine deferred chilled orders are individually feasible; joint constraints and
the policy determine which are omitted. The Style order S1-078 is individually
impossible because 40.660 m³ exceeds every available vehicle's volume limit.

The optimality certificate covers chilled allocation with fixed ambient packing.
Arrival-window checks are diagnostics under a no-return simulation; four unloads
finish after outlet close despite on-time arrivals, all before 08:00. Fuel is a
one-day estimate and cannot establish weekly compliance without earlier usage.

Tracked reports are in `task2b/reports/`. Per-order reasons, trip manifests,
timelines, hypothetical submissions and fuel details remain local in ignored
`task2b/data/`. Source datasets and model binaries remain ignored.

The 2026-10-07 regression run used Python 3.11.0 with the pinned package versions.
Earlier Task 1/2A artefacts recorded Python 3.11.2. Retraining preserved Task 1
service predictions and changed probabilities by at most 2.22e-16; Task 2A rounded
forecasts changed by at most 0.002 m³ total and 0.001 m³ chilled. The refreshed
outputs and Task 2A model summary accompany this integration so they match the
current local models. Model configuration and reported validation metrics did not
change. See `task2b/reports/regression_review.txt`.
